# CSE 163 Final Project
Using Machine Learning to Analyze Social Media Addiction and Student Outcomes

Authors: Kimberly Gu, Isabella Le

## Project Overview

This project analyzes the **Students Social Media Addiction** dataset to investigate patterns in social media addiction and student outcomes. The project includes exploratory data analysis (EDA) and machine learning models for two research questions:

Research Questions
How do social media addiction mean scores vary across different countries?
Can social media addiction scores predict relationship conflicts?
Can we predict a student’s level of social media addiction based on mental health and sleep duration?

We use the Social Media Addiction vs. Relationships dataset from Kaggle:
https://www.kaggle.com/datasets/adilshamim8/social-media-addiction-vs-relationships

The project uses:
- **pandas** for data loading and manipulation
- **matplotlib** and **seaborn** for visualization
- **scikit-learn** for regression models
- **PyTorch** for the neural network model

## Submitted Files 
### Python Files
- **summarize_csv.py**
Reads the CSV file and generates summary statistics for all variables in the dataset.
It writes seven-number summaries for quantitative variables, and category counts for
categorical variables into a text output file.

- **eda_plots.py**
Creates visualizations to explore relationships in the dataset.
It generates two plots:
Bubble plot: Addiction Score vs Relationship Conflicts
Scatter plot: Mental Health vs Sleep Hours (colored by Addiction Score)
Images generated:
addiction_vs_conflicts_bubble.png
mental_health_sleep_addiction_scatter.png
This script loads the dataset and saves the images automatically.
- **qr2_ml.py**
This script trains and evaluates machine learning models for the research questions.
The script prints model results and conclusions in the terminal. 

- **Q3.py**
This scripts runs and trains different machine learning models for research question 3.
The script uses linear regression and neural network to see the results

- **QR1_PROJECT.py**
This script runs and finds the mean average of social media addiction scores (hours spent on a social media platform)
for every country within our dataset and creates a visualization to see the distribution
of scores

- **test_file (1).py**
This script runs and has assert statements to ensure
our code is running properly and outputs correct information
ensuring our code is validated 

### Output/Data Files
- **social_media.csv**
Main dataset used for all analysis
- **summary_output.txt**
Output generated by hw1.py containing variable summaries
- **test.csv**
Parts of the main dataset, Students Social Media Addiction that is used for smaller testing,

## How to Run the Project
1. Make sure the above files are in the same directory
2. Install required libraries
   Run this command in the terminal:
   pip install pandas matplotlib seaborn scikit-learn torch
4. Generate data summary
   Run: python summarize_csv.py
   This will generate: variable_summary.txt
6. Generate EDA Visualizations
   Run: python eda_plots.py
   This will produce two figures: addiction_vs_conflicts_bubble.png, mental_health_sleep_addiction_scatter.png
7. Run Code For Visualization
   Run: QR1_PROJECT.PY
   This will produce one visualization: Plots the mean average social media addiction scores for each country
9. Run machine learning model
   Run: python qr2_ml.py
   This will print: linear regression results, ridge regression results
10. Run Machine Learning model
   Run: python Q3:
   This will print: Linear Regression Result, Visualization, and Neural Network Result
11. Run Testing File
    Run: test_file (1).py
    This file will ensure our code is working as properly by using assert statements
